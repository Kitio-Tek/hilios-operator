# OpenSSF Self-Attestation

This document tracks how the project meets the OpenSSF Best Practices criteria.
The badge in the README will be updated to point to a real
[bestpractices.dev](https://www.bestpractices.dev/) entry once the
self-attestation form is filled in.

## Coverage of basic criteria

- The project is hosted on GitHub with public history.
- It uses semantic versioning and tags releases.
- All commits are made over a verified channel (signed pushes via SSH).
- The default branch is protected by required CI checks.
- A LICENSE file is present (Apache 2.0).
- A SECURITY.md file describes the disclosure process.
