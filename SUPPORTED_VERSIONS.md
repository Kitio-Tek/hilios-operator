# Supported Versions

While HILIOS Operator is in 0.x preview, only the most recent minor release
receives security updates. Patch releases land on `release-MAJOR.MINOR`
branches.

| Version | Supported |
|---|---|
| 0.5.x | Yes |
| 0.4.x | Security fixes only |
| 0.3.x | No |
| 0.2.x | No |
| 0.1.x | No |

## Supported Kubernetes versions

| Kubernetes | Supported |
|---|---|
| 1.30 | Yes |
| 1.29 | Yes |
| 1.28 | Best-effort |
| < 1.27 | No |
